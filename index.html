Windows용 실행파일을 ZIP 형태로 만들고 테스트하는 개발 버전입니다. 설치 마법사나 관리자 권한 없이 실행하는 포터블 형태이며, 첫 리허설부터 ABBA 결과까지 로컬 브라우저에서 열립니다.

코드 서명이 없는 실험용 빌드입니다. Windows 보안 경고가 나오면 무리해서 실행하지 말고 빌드 출처와 SHA-256을 확인하세요.

ZIP을 받았다면

  1. GitHub에 로그인하여 프리릴리스 Assets에서 ZIP 다운로드
  2. 받은 ZIP을 브라우저에서 검사해 SHA-256과 파일명을 확인
  3. ZIP 압축을 풀어 GameFit-Beta 폴더 확인
  4. GameFit-Beta 폴더에서 GameFit-Beta.exe 실행
  5. 브라우저가 열리면 첫 CSV 리허설 또는 합성 샘플로 시작
확인: 정식 설치파일·결제 미출시. 실제 Windows 게임 측정·통계 판정의 현실 정확성 및 코드 서명은 아직 검증되지 않았습니다. 포터블 베타는 비공개 GitHub 프리릴리스로 제공되며 일반 대중에게 공개 배포되지 않습니다.
Good to know

설치하기 전에
궁금한 것들.

GitHub에 로그인해야 다운로드할 수 있나요?

네. 현재는 비공개 저장소의 개발용 아티팩트이며, 저장소 읽기 권한을 가진 사용자만 내려받을 수 있습니다. 일반 대중에게 배포하는 정식 설치파일은 아닙니다.

GameFit이 게임 설정을 자동으로 바꾸나요?

아니요. CPU·GPU 설정을 변경하거나 시스템을 자동 최적화하지 않습니다. 로컬 CSV 측정 데이터를 분석하는 프로그램입니다.

측정 파일이 서버로 전송되나요?

포터블 실행기를 통해 브라우저와 내 PC의 127.0.0.1 FastAPI 서버 사이에서만 처리됩니다. GameFit 자체에는 클라우드 업로드 기능이 없습니다.

정확한 FPS 개선이 인증되나요?

아니요. 분석 엔진은 데이터 조건을 검토하고 잠정적인 관측을 보여줍니다. 결과를 실제 성능 향상의 확정 근거나 공인 측정으로 해석하면 안 됩니다.
