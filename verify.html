Windows 릴리스 비공개 · 검증 전

비공개 저장소 접근 권한이 있어야 원본 릴리스 파일을 볼 수 있어.

무결성 일치는 안전성 인증이 아니야. SHA-256이 같다는 것은 기준에 등록된 ZIP과 바이트가 일치한다는 뜻일 뿐, 개발자 신원, 악성코드 부재, 코드 서명, 성능 향상을 증명하지 않아. Windows 보안 경고는 무리해서 우회하지 마.

파일을 확인한 다음

  1. ZIP 해시가 일치할 때에만 배포 파일이 기준값과 같다고 판단해.
  2. GitHub 원본 프리릴리스와 체크섬을 독립적으로 확인하고, 보안 경고가 나면 실행을 보류해.
  3. 진행하기로 선택했다면 ZIP을 압축 해제한 뒤 GameFit-Beta/GameFit-Beta.exe를 실행해.
  4. 브라우저가 열리면 CSV 하나로 첫 측정 리허설을 진행해. 실제 게임 측정 품질은 별도 검증 대상이야.
