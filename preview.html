GAMEFIT E7 / EXPLAIN THE EVIDENCE

FPS가 올랐다는 말,
얼마나 믿을 수 있을까?

아래는 실제 사용자의 PC가 아닌 **합성된 예시 데이터**야. 한 번의 높은 FPS보다 측정 조건과 자연 변동을 먼저 확인해야 하는 이유를 클릭 한 번으로 볼 수 있어.

브라우저 예시 · 실제 FPS 측정 아님
1. 예시 선택2. 판단 이유 확인3. 로컬 분석 방법 확인

01. 어떤 결과를 살펴볼까?

성능이 좋아 보이는 상황도 대조군 상태에 따라 판정이 달라질 수 있어. 실제 사용법을 보기 전에 서로 다른 세 상황을 선택해 봐.

잠정적인 개선 후보

A/A 대조군 차이 (합성)0.7%
A/B 평균 FPS 변화 (합성)+12%
A/B 하위 FPS 변화 (합성)+5%

동일 설정의 변동이 작고, 변경 후 평균과 하위 FPS 모두 개선된 예시야. 그래도 실제 실험에서는 다른 날의 반복 측정이 필요해.

이 화면의 숫자와 판정은 설명용으로 미리 작성된 합성 사례야. 로컬 FastAPI 엔진의 분석 결과를 직접 연결하거나 실제 게임을 자동 측정하지 않아.

02. 실제로 해보고 싶다면?

STEP 1 · CSV 준비

Windows에서 PresentMon의 원시 프레임 CSV를 수집하고, E5에서 올바른 게임 프로세스 데이터를 분리해.

STEP 2 · 대조군 검사

동일 설정 A₁·A₂를 각 3~5회 측정해 자연 변동을 확인해.

STEP 3 · 실험 결과 확인

설정을 한 가지 바꾼 B 측정 뒤 E6에서 잠정 비교 결과와 재측정 사유를 확인해.

무료 데모 다운로드·베타 상태 확인 받은 Windows ZIP 해시 확인

개발 단계의 실행 가이드이며 정식 설치 프로그램은 아직 제공되지 않아. 외부 결제와 서버 업로드는 없고, 실제 PC의 측정·통계 신뢰도는 추가 검증이 필요해.
